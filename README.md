A colossal galaxy jellyfish rises over a tiny night city — drawn pixel by pixel in code, no image assets. main.ts renders the scene procedurally (distance-field shapes, additive glow, a hand-rolled PNG encoder) and writes it as entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
